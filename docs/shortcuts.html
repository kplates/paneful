Keyboard shortcuts

Every binding in Paneful, grouped by what they do. Shortcuts use ⌘ on macOS / Ctrl on Linux unless noted.

General

ShortcutAction
⌘ + POpen command palette
⌘ + DToggle sidebar
⌘ + Shift + GToggle source control panel
⌘ + FSearch the focused terminal's scrollback

Panes

ShortcutAction
⌘ + NNew pane (vertical split)
⌘ + Shift + NNew pane (horizontal split)
⌘ + WClose the focused pane
⌘ + 1 – 9Focus pane by index
Ctrl + Shift + ←/→/↑/↓Move focus to the adjacent pane
Shift + ←/→/↑/↓Swap the focused pane with the adjacent one

Layout

ShortcutAction
⌘ + TCycle through layout presets
⌘ + RAuto-pick the best layout for the current pane count

Terminal text

These work inside any terminal pane, including scheduled-run viewers. They paper over things the browser would otherwise eat, mapping them to what your shell expects.

ShortcutSendsResult
Shift + EnterCtrl+V + LFInserts a literal newline in the command buffer (no submit)
⌘ + ←Ctrl+ACursor to line start
⌘ + →Ctrl+ECursor to line end
⌘ + BackspaceCtrl+UClear line
